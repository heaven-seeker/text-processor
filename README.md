# Advanced Text Processor (CLI)

Консольная утилита на языке C для сложной обработки и анализа мультиязычных текстов. Программа использует широкие символы (`wchar_t`) для корректной работы с кириллицей и другими кодировками.

## Возможности
Инструмент предоставляет следующие функции обработки текста:
1. **Анализ уникальности**: Поиск и вывод слов, которые встречаются в тексте только один раз.
2. **Форматирование дат**: Автоматический поиск дат в формате `ДД месяц ГГГГ г.` и их замена на стандартизированный формат `DD/MM/YYYY`.
3. **Сложная сортировка**: Сортировка предложений по значению произведения длин всех слов в предложении.
4. **Умная фильтрация**: Удаление предложений, содержащих специальные символы (`#`, `№`), если в них отсутствуют цифры.
5. **Поиск по маске**: Вывод слов, состоящих только из символов заданного ключевого слова.

## Сборка
Проект собирается с помощью `gcc` и `make`.

```bash
make

```

## Использование

Запустите программу и введите номер команды:

* `0`: Вывод обработанного текста (удаление дубликатов и лишних пробелов).
* `1`: Вывод уникальных слов.
* `2`: Стандартизация дат.
* `3`: Сортировка предложений.
* `4`: Удаление предложений по спецсимволам.
* `5`: Справка.
